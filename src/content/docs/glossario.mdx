---
title: Glossário
description: Termos canônicos para falar sobre inteligência artificial em português do Brasil.
---

Este glossário define o uso preferencial dos termos nesta documentação. Em nomes de
produtos, APIs e citações, a grafia original pode ser preservada.

| Termo (EN) | Tradução/uso em PT-BR | Definição curta | Traduzir? |
| --- | --- | --- | --- |
| agent | agente | Sistema que observa contexto, decide ações e usa ferramentas para alcançar um objetivo. | Sim |
| agentic workflow | fluxo agentivo | Fluxo em que o modelo participa de decisões e ações encadeadas. | Sim |
| attention | atenção | Mecanismo que pondera relações entre partes da entrada. | Sim |
| embedding | embedding | Representação vetorial usada para comparar significado ou estrutura. | Não |
| evals | avaliações | Testes sistemáticos para medir qualidade, segurança ou utilidade. | Sim |
| fine-tuning | ajuste fino | Treinamento adicional de um modelo com dados específicos. | Sim |
| grounding | ancoragem | Conexão da resposta com fontes, dados ou ferramentas verificáveis. | Sim |
| guardrails | barreiras de segurança | Regras e controles que limitam comportamentos indesejados. | Preferir tradução |
| hallucination | alucinação | Saída plausível, porém incorreta, sem suporte suficiente. | Sim |
| inference | inferência | Execução de um modelo treinado para produzir uma saída. | Sim |
| LLM | modelo de linguagem de grande escala | Modelo treinado para processar e gerar linguagem. | Traduzir na primeira ocorrência |
| prompt | prompt | Instrução e contexto fornecidos ao modelo. | Não |
| prompt injection | injeção de prompt | Tentativa de manipular instruções ou contexto para alterar o comportamento. | Sim |
| retrieval | recuperação | Busca de informações relevantes em uma coleção ou sistema externo. | Sim |
| reranking | reordenação | Nova ordenação dos resultados recuperados por relevância. | Sim |
| chunking | particionamento | Divisão de documentos em unidades menores para processamento. | Preferir tradução |
| context window | janela de contexto | Quantidade máxima de tokens considerada em uma chamada. | Sim |
| token | token | Unidade de texto processada pelo modelo; não equivale sempre a uma palavra. | Não |
| temperature | temperatura | Parâmetro que influencia a variação das amostras geradas. | Sim |
| tool use | uso de ferramentas | Execução de funções, APIs ou comandos externos pelo modelo. | Sim |
| tool calling | chamada de ferramenta | Formato estruturado para solicitar uma ação externa. | Preferir tradução |
| human-in-the-loop | pessoa no circuito | Revisão ou decisão humana inserida em um fluxo automatizado. | Sim |
| retrieval-augmented generation | geração aumentada por recuperação | Geração apoiada por conteúdo recuperado de fontes externas. | Traduzir na primeira ocorrência |
| observability | observabilidade | Capacidade de entender o comportamento do sistema por sinais e registros. | Sim |
| red teaming | teste adversarial | Busca deliberada por falhas, abusos e caminhos de ataque. | Preferir tradução |
| benchmark | referência de comparação | Conjunto ou resultado usado para comparar sistemas. | Preferir tradução |
| zero-shot | sem exemplos | Execução de uma tarefa sem exemplos explícitos no prompt. | Não |
| few-shot | com poucos exemplos | Execução orientada por um pequeno conjunto de exemplos no prompt. | Não |
